# 微信固定命令方案

日期：2026-10-03。

状态：已实施 Hermes风格固定命令，真实微信验收待主人确认；普通自然语言工作入口和既有权限边界保留。

## 交互原则

- 工作台控制使用固定斜杠命令，直接由本地代码解析，不增加模型意图识别。
- 普通咨询和开发请求仍用自然语言，以微信原文进入当前长期 Thread。
- 命令与子命令采用小写英文，按完整命令和参数匹配，不使用子串猜测；参数错误或未知命令直接返回用法，不降级为模型任务。
- 控制命令不参加2秒文本合并，也不与待处理图片拼接；项目列表、ROADMAP进度、任务状态与取消可即时处理，会话和模型运行信息查询沿用 App Server会话锁。
- 只允许当前微信原文提供控制授权，附件、历史或模型回复不得触发命令。
- 支持带空格路径的引号参数，文件路径仍受当前项目、类型、敏感文件和大小限制约束。
- 旧中文快捷说法在迁移阶段保留，帮助以固定命令为准；不继续扩大自然语言正则集合。

## 命令清单

| 命令 | 含义与现有功能映射 |
| --- | --- |
| `/help` | 显示命令与示例 |
| `/projects` | 列出本地可用项目，标记当前项目 |
| `/project` | 查看当前项目和会话模式 |
| `/project wxbot` | 切换到指定项目 |
| `/project add "D:\projects\example-app"` | 登记已存在的绝对目录，使用目录名作为项目名；支持嵌套目录、其他盘符和非 Git项目，重启后保留，不自动切换 |
| `/chat` | 切回独立普通聊天会话 |
| `/progress` | 读取当前项目 ROADMAP正式进度 |
| `/next` | 按 ROADMAP恢复顺序读取下一步 |
| `/tasks` | 列出运行任务和等待队列 |
| `/agents` | `/tasks`别名 |
| `/task` | 查看当前项目运行状态或最近任务结果 |
| `/stop` | 优先取消当前项目最新排队任务，无排队则取消运行任务；不停止后台服务 |
| `/error` | 查看当前项目最近任务的脱敏失败原因 |
| `/accept` | 确认当前项目最近待验收任务通过，并向 ROADMAP写入明确验收记录；不批量改变其他事项状态 |
| `/sessions` | 列出当前范围的已有 Codex会话 |
| `/sessions search 关键词` | 搜索会话名称与安全内容 |
| `/status` | 查看当前绑定会话和运行信息 |
| `/sessions show 2` | 预览列表第2个会话，不改变绑定 |
| `/resume 2` | 切换并绑定最近列表第2个会话 |
| `/model` | 查看当前模型、提供方和推理等级，不修改模型 |
| `/usage` | 查看当前会话 Token用量 |
| `/context` | 查看上下文窗口信息 |
| `/new`、`/reset` | 清空当前会话上下文，保留其他会话、白名单和消息去重 |
| `/compress` | 压缩当前上下文，保留会话 |
| `/reset-ai-state` | 预览清空全部 AI状态的范围与风险 |
| `/reset-ai-state confirm` | 由同一白名单用户在5分钟内确认预览，不跳过二次确认 |
| `/diff --stat` | 查看当前项目最近任务的修改摘要 |
| `/diff README.md` | 查看单个文件的修改 |
| `/diff` | 查看当前项目最近任务原始 diff |
| `/rollback` | 列出当前项目可用恢复记录 |
| `/rollback latest` | 预览恢复最近任务修改的范围和冲突 |
| `/rollback confirm` | 确认已经预览的具体目标，执行前继续检查后续变化冲突；后台重启后须重新预览 |
| `/send README.md` | 发送当前项目内允许的文本或音频文件，保留现有发送安全检查 |

`projects`／`tasks`／`sessions`用复数表示列表，`project`／`task`表示当前对象。`show`表示预览，`resume`表示绑定，`search`表示搜索，`confirm`只确认已存在的具体预览，不扩大授权范围。

与 Hermes已有能力一致的名称采用 `/help`、`/new`、`/reset`、`/compress`、`/stop`、`/model`、`/usage`、`/context`、`/sessions`、`/resume`、`/status`和 `/agents`；项目管理、ROADMAP、任务验收、文件发送和 checkpoint使用本项目扩展。不增加当前项目没有实现的 Hermes能力。参考：[Hermes斜杠命令](https://hermes-agent.nousresearch.com/docs/reference/slash-commands/) 。

## 保持自然语言的工作请求

修改代码、测试、构建、提交、推送和内容创作继续直接表达，例如“修改 README并运行测试”“提交代码”。不新增 `/exec`或通用 `/confirm`，也不为每一种工作创建命令。

后台进程启动、停止和重启继续使用本机 CLI的 `start`／`stop`／`status`／`restart`与已有桌面 Skill。微信命令不能在服务停止后接收，因此本轮方案不增加微信远程启停命令。

## 实施后的验收条件

- 每条命令映射现有能力，未实现能力不得出现在帮助中；完整匹配、缺参、多余参数、未知命令和带空格文件路径均有自动化验证。
- 列表序号沿用最近一次列表结果；越界或没有列表时提示重新列出，不猜目标。
- 微信实测列表、项目切换、忙时查询与取消、会话绑定、上下文操作、文件发送及恢复确认。
- 普通消息保持原文，无前置模型意图分类；附件正文中出现命令不能授权执行。
- 项目规则和技术设计已先于实现更新；自动化通过不等于真实微信验收完成。
